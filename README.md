# TrueWheels

## Frontend Phase 31 of 50

Reviews and ratings system.

### Delivered

- Reusable review cards with star ratings, reviewer verification, photos, and helpfulness voting
- Dealer, private-sale, and auction purchase-type badges
- Review summary with average score, star breakdown bars, and recommendation rate
- Rich review-writing modal with overall and category ratings
- Optional photo uploads with local previews and removal controls
- Review title, 1,000-character experience text, and recommendation choice
- Positive and negative review filters
- `/reviews` route integration with local review creation state

Persistent review storage, moderation workflows, verified transaction enforcement, image uploads, profile/listing integrations, anti-abuse controls, and aggregate recalculation remain future work.
